Minima is a Simple but Universal Theme for Oh My Posh!, built for Speed, Adaptability, Features and Maximum Portability. Made for ALL Terminal Color Schemes!

Key Features

  • No need for a Nerd Font! ✓
  • Extremely minimal and fast! ✓
  • Consistent across all systems and color schemes! ✓
  • Handles root and administrator sessions using # instead of $. ✓
  • No feature creep! Includes Git checks, execution time, and highlights $ or # in red when a command fails. ✓
  • Works perfectly in any terminal, even GARBAGE terminals like conhost.exe! ✓

Made for Oh My Posh! by @jandedobbeleer.
